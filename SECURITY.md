# Security policy

## Reporting

Do not open a public issue for suspected credential exposure, private data, or a security vulnerability.

Use GitHub's private vulnerability reporting for this repository. Include the affected file or commit, the type of exposure, and enough redacted detail to reproduce the finding.

## Scope

This repository is a static, non-production reference implementation. It must not contain or connect to production services, data, credentials, or infrastructure.

If sensitive material is discovered, assume it has been publicly accessible. Remove it from every public ref, assess whether credentials or identifiers require rotation, and document the response privately.
