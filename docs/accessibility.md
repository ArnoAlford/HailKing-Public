# Accessibility approach

The public showcase aims for a strong keyboard and screen-reader baseline:

- semantic landmarks and heading order;
- a visible skip link and high-contrast focus treatment;
- descriptive alternative text for meaningful images;
- captions and ownership context for reference media;
- responsive layouts that do not require hover; and
- reduced-motion support for users who request it.

The project intentionally uses system fonts and no client-side interaction library. Contributors should verify keyboard navigation, text resizing, color contrast, and responsive reflow before proposing a change.
