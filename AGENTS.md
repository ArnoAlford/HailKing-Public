# Repository instructions

- This is a sanitized, static public reference project. Preserve the deny-by-default rules in `PUBLIC-SCOPE.md`.
- Never add production routes, integrations, identifiers, data, media, credentials, environment files, operational documentation, or history from another repository.
- Before changing Next.js code, read the relevant installed documentation in `node_modules/next/dist/docs/`.
- Required verification is `npm run lint`, `npm run build`, and `npm audit`.
