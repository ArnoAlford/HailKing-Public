# Contributing

Contributions must preserve the strict public/private boundary described in [PUBLIC-SCOPE.md](PUBLIC-SCOPE.md).

Before opening a pull request:

```bash
npm ci
npm run lint
npm run build
npm audit
```

Do not submit production code, data, screenshots, media, logs, environment files, account identifiers, operational documentation, or copied history. Public issues and pull requests are permanently unsuitable for sensitive reports; use the process in [SECURITY.md](SECURITY.md).
